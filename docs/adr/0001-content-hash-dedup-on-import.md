# Content-hash deduplication on import

导入图像时，基于像素内容计算哈希值，与已有 Record 的哈希比对。若匹配则拒绝导入并提示"图像已存在"，而非创建重复记录。

## Considered Options

- **允许重复**：每次导入都创建新 Record。被放弃——用户重复导入同一张图是常见误操作，静默允许会导致检索结果中出现自身以外的"最相似图像就是自己"的尴尬情况。
- **基于文件名去重**：同名文件拒绝重复导入。被放弃——不同文件名可能是同一内容（如 `cat.ppm` 和 `cat_copy.ppm`），基于文件名不可靠。
- **基于像素内容哈希去重**（已选择）：对解码后的像素数据做哈希，比对已有 Record 的哈希值。内容相同即判定为重复，与文件名无关。

## Consequences

- `image_record_t` 需要增加哈希字段
- 每次导入需要额外一次全表扫描来完成哈希比对
- 哈希算法选择（MD5 / SHA256 / 简单校验和）留待实现时决定
